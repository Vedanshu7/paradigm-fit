# Detailed Design

How each requirement is met, file by file. Paths are under `app/src/paradigm/` unless they start with `../`.

| ID                          | Statement                                                                                                                                                                                                                                                                                                                                                                                                                | Traces up                                                                                                                                                                                                                          |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <span id="dd-1">DD-1</span> | `domain/duration.ts` parses an entry: trim, match `^\d+(\.\d+)?$`, then check the range (block 1 to 3600 s, scan 1 to 7200 s). A block under 10 s counts as short. `domain/paradigm.ts` sets a tolerance of 1e-9 s; the verdict and the per-block timing both use it, so decimal sums with float noise still compare equal.                                                                                              | [REQ-2](../requirements/software-requirements.md#req-2), [REQ-4](../requirements/software-requirements.md#req-4), [REQ-8](../requirements/software-requirements.md#req-8)                                                          |
| <span id="dd-2">DD-2</span> | `domain/check.ts`: `checkParadigmFit` takes the typed strings and returns either `unchecked` (which fields failed, and why) or `checked` (total, timings, verdict). Short-block hints come with both.                                                                                                                                                                                                                    | [REQ-3](../requirements/software-requirements.md#req-3), [REQ-5](../requirements/software-requirements.md#req-5), [REQ-8](../requirements/software-requirements.md#req-8)                                                          |
| <span id="dd-3">DD-3</span> | `ui/composables/useParadigm.ts` holds the typed strings and one computed `check`. `provideParadigm` installs it at the root; `useParadigm` reads it in any component.                                                                                                                                                                                                                                                    | [REQ-3](../requirements/software-requirements.md#req-3), [REQ-7](../requirements/software-requirements.md#req-7)                                                                                                                   |
| <span id="dd-5">DD-5</span> | `ui/ParadigmFitView.vue` lays out the three panels. `ui/verdict/FitVerdict.vue` shows the verdict (icon, title, sentence) and the scan field. `ui/table/BlockTable.vue` shows one row per block from `ui/lib/rows.ts`: a text input, a note (error or hint), start time, and "full", "none" or "X of Y s". Verdict and rejection wording is in `ui/lib/messages.ts`.                                                     | [REQ-2](../requirements/software-requirements.md#req-2), [REQ-5](../requirements/software-requirements.md#req-5), [REQ-7](../requirements/software-requirements.md#req-7), [REQ-8](../requirements/software-requirements.md#req-8) |
| <span id="dd-6">DD-6</span> | `ui/timeline/ParadigmTimeline.vue` draws the bars from `ui/lib/bars.ts`, a ruler and the scan-end marker, all on one scale of `max(total, scan)`, at least 1 s. A bar's width is exactly its share of the scale; its label shortens to the first word, then hides, when it does not fit. `ui/lib/ticks.ts` picks a tick step that gives about 20 ticks. The timeline is replaced by a message while an entry is invalid. | [REQ-5](../requirements/software-requirements.md#req-5), [REQ-6](../requirements/software-requirements.md#req-6)                                                                                                                   |
| <span id="dd-7">DD-7</span> | `infrastructure/loadParadigm.ts` reads `paradigm.json` at build time and rejects an unknown block type. `../shared/format.ts` prints numbers with at most two decimals; a value that would show as 0 prints `< 0.01`.                                                                                                                                                                                                    | [REQ-3](../requirements/software-requirements.md#req-3), [REQ-7](../requirements/software-requirements.md#req-7)                                                                                                                   |

## Check outcomes

| In code     | When                        | On screen                         |
| ----------- | --------------------------- | --------------------------------- |
| `unchecked` | an entry does not parse     | Cannot check; the field is marked |
| `fits`      | total equals the scan       | Fits                              |
| `underrun`  | total is less than the scan | Fits, scan time unused            |
| `overflow`  | total is more than the scan | Does not fit                      |
